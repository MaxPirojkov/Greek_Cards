# Греческие карточки

Карточки для изучения греческих слов с озвучкой.

- **Рус → Гре**: русское слово, тап переворачивает карточку, показывает греческое и озвучивает его.
- **Гре → Рус**: греческое слово с кнопкой «Слушать», тап показывает перевод.
- **На слух**: только кнопка голоса, тап показывает слово и перевод.

Слова добавляются во вкладке «Мои слова» и хранятся в браузере устройства (localStorage).
Озвучка идёт через греческий голос, встроенный в устройство (Web Speech API, `el-GR`).

Сайт публикуется через GitHub Pages: Settings → Pages → Branch `main`.
